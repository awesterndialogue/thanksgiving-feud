FRIENDLY FEUD — THANKSGIVING EDITION
Modernized one-file replacement for your church's existing GitHub Pages game.

WHAT CHANGED
- Projector board redesigned to retain the church's original PowerPoint look:
  illuminated oval marquee, fall leaves, orange answer panels, two-column board,
  side scores, turkey, and gold/orange palette.
- Larger answer text and smoother reveal/strike/score animations.
- All 48 Thanksgiving-specific demo questions and answers retained.
- Four-round mode (1x, 1x, 2x, 3x) remains the default.
- Five-round mode (1x, 1x, 1x, 2x, 3x) is now available in operator controls.
- Optional original audio import from your own extracted WAV files. Because the
  licensing of the purchased package is not established, no original music/audio
  or other artwork is redistributed in this website.
- Existing operator functions stay: reveal any answer, track wrong answers,
  steal, award, manual score correction, undo, three matches, question editing,
  JSON import/export, and autosave on this computer.

HOW TO UPDATE YOUR CURRENT GITHUB WEBSITE
1. Unzip this package. You will find a file named index.html.
2. Open your repository at https://github.com/awesterndialogue/thanksgiving-feud
3. Click Code if not already on the Code tab.
4. Click Add file (above the file list) -> Upload files.
5. Drag THIS NEW index.html into the upload area. It should replace the old
   index.html at the top level of the repository.
6. Scroll down and click Commit changes. Confirm if prompted.
7. Revisit https://awesterndialogue.github.io/thanksgiving-feud/
   GitHub Pages may take a few minutes to publish. If you still see the old
   design, refresh the page (Cmd+Shift+R on your Mac).
8. Open a projector screen and practice a full round before using the game live.

PRESERVING GAME DATA
The app intentionally uses the same browser storage key as the first version.
Existing games and question edits should therefore carry over in the same
browser and profile on the same computer. Data from one computer is not
synchronized to other computers. Before major changes, export your question
library in the operator controls as a JSON backup.
Changing 4/5 round mode resets all three matches and scores, but does not
remove questions or question edits. The app asks for confirmation first.

OPTIONAL ORIGINAL AUDIO FROM YOUR POWERPOINT
The web app ships with its own synthesized sounds. If you have permission
under the PowerPoint package license, you can optionally load the extracted
original sounds on the church tech-room computer without publishing them:
- Locate the previously extracted sound WAVs from the original presentation.
- In Operator -> Question management -> Optional original PowerPoint sound
  effects, choose "Load local WAV sound pack".
- Select one or more WAV files with names beginning with:
  answer_reveal.wav, wrong_answer_short.wav, crowd_cheer.wav,
  game_theme_long.wav, 6s_game_theme.wav.
- Sounds are kept in this browser's local storage if allowed and have a
  synthesized fallback. Click Play intro to test the theme. Confirm AV output
  before the live event. If you lack permission, use the included sounds.

IMPORTANT LIMITATIONS
- The 48 questions have illustrative (not survey-derived) point totals.
  Do not describe the values as findings from an actual survey.
- The operator and projector windows synchronize on the SAME computer,
  SAME browser profile, and SAME website address. No second-device sync.
- Refreshing should preserve saved scores/progress, but always rehearse.
- No Fast Money round is included, per your church's format.
- This is an unofficial church game, not affiliated with the TV show.
